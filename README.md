# ConvergioPlatform (ARCHIVED)

> **This repository has been archived and is no longer maintained.**

All development has moved to **[Roberdan/convergio](https://github.com/Roberdan/convergio)**.

## What happened

ConvergioPlatform was the original monorepo for the Convergio project. The codebase has been fully migrated to [convergio](https://github.com/Roberdan/convergio) — a clean Rust workspace with 30+ crates, all agents, hooks, rules, and infrastructure.
