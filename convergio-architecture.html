10. End-to-End Execution Flow

/solve (Opus)→ /planner (Opus 1M)→ Review (Sonnet)→ DB persist→ /execute (Codex)→ Thor (Opus, 10 gates)→ Merge + Done
Each step is hook-enforced. Skipping = blocked. After every task: cvg checkpoint save → update DB → next task or Thor. Max 4 tasks/wave. Cascading fix threshold: 3 → STOP. Executors cannot set done — only Thor (via cvg plan validate) promotes submitted → done.
